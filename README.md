# SISTEMA AFRONEXIA
Sistema de Información basado en IA para la Promoción Cultural y Turística Afrodescendiente de Barrancabermeja.

## Despliegue:
1. Base de datos: Ejecutar `database/init.sql` en PostgreSQL.
2. Backend: `cd backend && npm install && npm run dev`
3. Frontend: `cd frontend && npm install && npm run dev`
